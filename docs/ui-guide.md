## 1. 界面布局

ChenDoc 采用经典的三栏式布局：**侧边栏 + 头部 + 内容区**。

### 1.1 侧边栏 (AppSidebar)

**位置**：屏幕左侧，固定定位

**宽度**：
| 状态 | 宽度 |
|------|------|
| 展开态 | 90px |
| 折叠态 | 56px |

**功能区域**：
- **品牌区域**：顶部显示 ChenDoc Logo 和名称，点击可折叠/展开侧边栏
- **导航菜单**：文档、知识库、回收站、审核、模板等入口
- **账户区域**：当前登录用户头像、名称
- **退出按钮**：退出当前登录

**切换断点**：宽度 ≤900px 时侧边栏自动转为抽屉式（滑入/滑出）

### 1.2 顶部栏 (AppHeader)

**位置**：页面顶部，固定定位 (`position: sticky`)

**高度**：52px (`--cd-header`)

**布局**：三栏自适应网格
```
[搜索框] [操作按钮区] [用户菜单]
```

**功能组件**：
- **搜索框**：全文搜索文档
- **操作按钮**：通知、新建等快捷操作
- **用户菜单**：头像下拉菜单，包含设置、主题切换、退出登录

**移动端响应**：宽度 ≤900px 时搜索框隐藏，菜单按钮显示

### 1.3 内容区

**布局**：剩余空间填充 (`flex: 1`)

**最大宽度**：1600px (`width: min(1600px, 100%)`)

**内边距**：
- 桌面端：`clamp(32px, 3.2vw, 56px)` 水平，`52px` 底部
- 移动端：无内边距，全宽布局

## 2. 主题切换

### 2.1 支持的主题

| 主题 | 说明 |
|------|------|
| `light` | 亮色模式（纯白背景） |
| `dark` | 暗黑模式（深灰背景） |
| `system` | 跟随系统设置 |

### 2.2 切换方式

在顶部栏用户菜单中选择「主题设置」，可切换三种模式。

### 2.3 CSS 变量系统

主题通过 CSS 自定义属性（变量）实现，主要变量：

**亮色模式**：
```css
--cd-bg: #ffffff;        /* 背景 */
--cd-ink: #111111;       /* 主文字 */
--cd-text: #333333;      /* 正文 */
--cd-border: #eeeeee;    /* 边框 */
--cd-accent: #0066cc;    /* 强调色 */
```

**暗黑模式** (`[data-theme="dark"]`)：
```css
--cd-bg: #0a0a0a;        /* 背景 */
--cd-ink: #f0f0f0;       /* 主文字 */
--cd-text: #d0d0d0;      /* 正文 */
--cd-border: #2a2a2a;    /* 边框 */
--cd-accent: #4d9fff;    /* 强调色 */
```

### 2.4 持久化

主题选择存储在浏览器 `localStorage`，键名：`chendoc_theme`

### 2.5 自动切换

当选择「跟随系统」时，系统主题变化会自动应用（通过 `matchMedia` 监听）

## 3. 文档列表页

### 3.1 页面结构

```
┌─────────────────────────────────────────────────┐
│ [标题区] 文档  数量                               │
│ [筛选标签] 全部 | 公开 | 私有 | 已加密             │
├─────────────────────────────────────────────────┤
│ [操作工具栏] 搜索 | 排序 | 视图切换 | 导入 | 新建   │
├─────────────────────────────────────────────────┤
│ ┌─────────────────────────┬───────────────────┐ │
│ │ [文档表格]               │ [工具箱侧边栏]     │ │
│ │ ☐ 标题 | 状态 | 修改时间 │ 最近活动          │ │
│ │ ☐ 标题 | 状态 | 修改时间 │ 快速操作          │ │
│ │ ☐ 标题 | 状态 | 修改时间 │ 存储空间          │ │
│ └─────────────────────────┴───────────────────┘ │
└─────────────────────────────────────────────────┘
```

### 3.2 核心功能

**筛选标签**：
- 全部、公开、私有、已加密

**搜索**：
- 标题搜索
- 最近搜索记录（存储在本地）
- 搜索结果高亮（`<mark>` 标签）

**批量操作**：
- 勾选多个文档
- 批量删除、批量移动
- 批量导出

**表格列**：
| 列 | 说明 |
|----|------|
| 标题 | 文档名称 + 预览文字 |
| 状态 | 公开/私有/已加密标签 |
| 修改时间 | 最后修改时间 |
| 操作 | 编辑、删除、分享 |

### 3.3 移动端适配

移动端（≤760px）自动切换为卡片列表布局：
- 顶部显示搜索栏
- 筛选标签横向滚动
- 底部固定操作工具栏（4 列网格）
- 新建按钮占整行

## 4. 快捷键和操作提示

### 4.1 编辑器快捷键

编辑器支持以下快捷键：

| 快捷键 | 功能 |
|--------|------|
| `Enter` | 打开/选中文档 |
| `Space` | 切换文档展开状态 |
| `/sp` | 插入短段落分隔符 |
| `/tp` | 插入长段落分隔符 |

### 4.2 文档树操作

| 操作 | 说明 |
|------|------|
| 点击标题 | 打开文档 |
| 点击展开箭头 | 展开/折叠子文档 |
| 键盘 `Enter` / `Space` | 触发打开或切换 |

### 4.3 全局操作提示

- **按钮悬停**：显示操作说明
- **输入框聚焦**：显示格式提示
- **保存状态**：显示「已保存」「保存中」「保存失败」状态

## 5. 响应式布局

### 5.1 断点定义

| 断点 | 宽度范围 | 布局调整 |
|------|----------|----------|
| 桌面大屏 | >1360px | 双栏工作区（文档+工具箱） |
| 桌面中屏 | 1181-1360px | 单栏文档，工具箱隐藏 |
| 桌面小屏 | 981-1180px | 单栏布局 |
| 平板 | 761-980px | 头部简化，侧边栏折叠 |
| 移动端 | ≤760px | 全屏卡片布局 |

### 5.2 断点样式表

```css
/* 平板适配 */
@media (max-width: 900px) { ... }

/* 小屏适配 */
@media (max-width: 760px) { ... }

/* 大屏双栏 */
@media (min-width: 1181px) { ... }

/* 桌面大屏 */
@media (max-width: 1180px) { ... }

/* 超大屏 */
@media (max-width: 1360px) { ... }
```

### 5.3 移动端特性

- **安全区域适配**：使用 `env(safe-area-inset-*)` 适配刘海屏
- **触摸优化**：
  - 按钮圆角增大（12px）
  - 点击反馈（`scale(0.98)` 缩放）
  - 手势滑动（列表横向滚动）
- **性能优化**：
  - 禁用动画（`prefers-reduced-motion`）
  - 图片懒加载

### 5.4 侧边栏响应

| 场景 | 行为 |
|------|------|
| 桌面端（>900px） | 固定显示，可折叠 |
| 移动端（≤900px） | 抽屉式，从左侧滑入 |
| 打开时 | 背景遮罩覆盖内容区 |

### 5.5 工具箱响应

| 场景 | 行为 |
|------|------|
| 超大屏（>1360px） | 显示在文档右侧（240px） |
| 大屏（1181-1360px） | 隐藏工具箱 |
| 中屏（981-1180px） | 工具箱移至文档下方 |
| 移动端（≤760px） | 工具箱隐藏 |

## 附录 B：常见问题

### Q1：侧边栏无法折叠？
**排查**：
1. 检查是否处于移动端（≤900px），移动端侧边栏为抽屉式
2. 刷新页面后重试

### Q2：主题不生效？
**排查**：
1. 确认浏览器支持 `prefers-color-scheme`
2. 清除 `localStorage` 后重试
3. 检查是否有浏览器插件覆盖主题

### Q3：移动端操作按钮无响应？
**排查**：
1. 确保已登录
2. 检查网络连接
3. 尝试刷新页面

### Q4：搜索结果不准确？
**排查**：
1. 确认文档内容已保存
2. 搜索最小单位为 2 个字符
3. 清除浏览器缓存后重试
